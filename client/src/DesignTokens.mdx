# Design tokens

Colors and fonts are defined once, as CSS variables in `src/styles.css` and as Ant Design theme tokens in
`src/context/ThemeContext.jsx`, so every component stays consistent in both themes.

## Typography

**Fraunces** for headings and big numbers:

<Typeset fontFamily="'Fraunces', Georgia, serif" fontWeight={700} fontSizes={[36, 28, 22]} sampleText="$5,200 earned in November" />

**DM Sans** for everything else:

<Typeset fontFamily="'DM Sans', system-ui, sans-serif" fontSizes={[16, 14, 12]} sampleText="Groceries · $86.40 · Nov 8, 2026" />

## Shape

- Corner radius: **10px** for cards, inputs and buttons (Ant Design `borderRadius`).
- Category colors come from 14 presets, shown on the [CategoryIcon](?path=/story/data-display-categoryicon--all-icons) page.
